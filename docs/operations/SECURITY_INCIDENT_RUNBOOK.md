# Security Incident Runbook

SEV1 covers funds, cross-tenant authorization, credential disclosure or unrecoverable data loss. Page the technical founder and operations founder immediately, contain within 15 minutes, and update affected users after facts are verified. SEV2 covers degraded auth, booking or notification paths. SEV3 is non-customer-impacting.

Open every incident with domain, primary/backup owner and the originating correlation ID. Preserve provider events and append a timeline; do not edit ledger or audit history. Contain with feature gates or credential rotation, reconcile funds, restore service, notify counsel/providers where required, then add a regression test and written resolution.

Synthetic rehearsals must cover: invalid admin access, forged payment signature, reconciliation mismatch, notification provider failure, privacy export attempt across customers and restore failure.
